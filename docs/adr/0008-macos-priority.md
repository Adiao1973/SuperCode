# ADR-0008：macOS 优先，Windows 平台延期

- 日期：2026-10-07
- 状态：接受（用户明确授权）

## 背景与授权

用户目前没有 Windows 机器，指令为“那调整一下路线，目前是没有 windows 机器可以验收的，全力研发 mac 平台”。P3-8 已在独立分支实现，本机回归通过，但 Windows 编译、CI、WebView2 和真实交互均未验证；P3-9 未启动。

## 决策

当前开发和 v1.0.0 交付范围聚焦 macOS。P3-8/P3-9 延期，不作为本轮 macOS 发布的前置出口；不将延期标为已验收。P3-8 代码保留 feat/p3-8-windows-runtime，不合 dev、不丢弃；CI 配置也仍在该分支，暂无执行记录。恢复 Windows 工作时，先同步当时 dev、运行 Windows CI，再完成实机与安装包出口。

原 P3-10 拆为 P3-10A macOS 整体回归与 P3-10B macOS 构建发布。先按流程预写阶段剧本，再验收已交付功能、修复缺陷、验证安装包；本决策不是发布执行，不改变 v0.3.0 已发布状态。P3-7 NativeDriver 仍为核心库范围，不由路线调整自动变成产品入口。

## 后果与验收门槛

macOS 工作不再因 Windows 环境缺失阻塞。平台门槛按明确批准的发布范围执行；本轮 macOS 的自动、真实模型、UI、安装启动验收仍全部必需。未来恢复 Windows 支持时也必须通过对应平台出口。不得声称双平台可用，或把 macOS 测试计作 Windows 验收。P2-6 ZCode 延期与 Claude 本机暂不处理的原约定继续有效。
