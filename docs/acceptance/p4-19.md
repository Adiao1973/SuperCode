# P4-19 统一空/错/加载/短反馈

状态：开发中。2026-10-13。

## 预写验收

- `just verify`：共用空/加载/错误与 Toast 生命周期、防刷屏、暂停/关闭；复制成功/失败与无未处理拒绝；读取失败重试仅查询、不产生派单/审批/生成/运行。
- 五页原生 macOS Tauri：空态/加载占位与错误可辨；模型保存与复制显示短提示，失败保留内联；错误重试恢复，无自动执行。
- 独立 fixture 验证读取失败及重试、剪贴板成功与减少动态；960×640 深浅可读，键盘可关闭 Toast、不抢输入焦点。通过后同步文档与 --no-ff 合入本地 dev，不发布。
