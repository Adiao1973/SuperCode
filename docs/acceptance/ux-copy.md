## 分析与小设计

视觉方向：沿用现有克制工作台，标题、状态和动作优先，减少常驻说明段落。
内容层次：直接操作 → 必要状态/影响 → 按需帮助。重复信息删除，键盘说明折叠；按钮保留清晰动作名称，不把陌生概念全部变成无标签图标。
交互：使用原生 details 渐进展示，不新增动效/依赖；既有焦点和减少动态保持。

- 设置：模型职责与保存/验证状态重复；删除长段重复说明，保留本机存储、文本模型选择和验证会调用 API。
- 指挥官：步骤与字段已经说明操作；缩短引导，执行确认前不运行仍明确。
- 会话：缩短快捷键提示与配置帮助，权限风险和错误保留。
- 看板：拖拽/键盘教学改为按需帮助，跨空间移动不改变执行归属仍可查。
- 审批：删除跨会话聚合教学横条，空态直说暂无请求，裁决信息不删。
- 搜索/详情：收短范围和空态，技术限制放在帮助内，完整目录/绑定/标识不删。
