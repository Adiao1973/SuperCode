## 预写验收

1. just verify 全绿，覆盖状态计数、无结果/截断、会话 UUID 映射和失败关闭、隐藏后持续执行、过期刷新不覆盖。
2. 原生 Tauri：合成并行/依赖计划显示排队与运行，前置全部成功才启动后继；失败后继跳过、取消不再派单。
3. 执行中切模块再返回不中断；结果进入正确历史会话且不启动任务，重启读取历史不重跑，失活 running 如实显示。
4. 宽/窄窗口核对结果可读与会话入口；原始 ACP id 与本地 UUID 不相同也能定位。记录证据后才能合 dev。
