# P2-6 ZCode StreamJson 验收

## 预写步骤

1. `just verify`：消息增量、工具状态、摘要去重、失败和取消的协议契约检查及现有检查全绿。
2. `supercode detect` 显示 ZCode 版本；参数能力探测必须确认支持 `stream-json`（官方 help 可能遗漏该参数）。仅支持 `--json` 的旧包应得到明确升级提示，无空轮次误报。
3. 独立 `/tmp/sc-p26-task` 和 SQLite 中 `supercode run --agent zcode --cwd /tmp/sc-p26-task '创建 hello.txt 内容 P26-ZCODE，再读回'`：消息流、write/read 工具时间线可见，文件内容正确，result 后 EndTurn、agent_id=zcode 落库。
4. 长任务取消后返回 Cancelled，ZCode 及孙进程无残留；无输出、非法 JSON 和失败结果均标记 failed。
5. macOS 桌面可选择 ZCode，显示“无法外部审批 / 完全访问”，权限模式和规则输入禁用。与 ACP agent 并行归属独立；重启后历史绑定 ZCode；不支持续聊时给出新建提示。
6. 认证和默认模型由 ZCode 自己管理；若当前 CLI 无流式协议或模型不可用，记录已完成范围与阻塞，保留进行中，不提前合入 dev。

参考：[官方 headless 实现](https://github.com/zai-org/ZCode/blob/main/apps/zcode-cli/packages/cli/src/prompt-command.ts)。
