# P3-3 计划持久化与执行状态机验收

## 预写验收

1. just verify 全绿；契约测试先失败再实现。
2. 文件 SQLite 创建计划后重开恢复计划/任务/目录/顺序；没有执行会话且不自动运行。无效计划或相对目录拒绝，不留半条计划。
3. 同一任务并发启动只有一个成功；独立任务同时更新若冲突需读取后重试，无状态丢失。依赖未成功不可启动；终态不得重跑。
4. 失败跳过全部后代但保留独立任务，全部终态生成失败汇总状态；正常全成功为 succeeded。
5. draft/running 取消原子保存，完成结果保留；显式恢复中断运行任务、取消未启动任务，不改变 draft/终态，不访问 agent。
6. 无 UI 变更；使用真实 SQLite 的集成测试为本任务验收，不以此代替 P3-2 真实模型验证。前置任务未完成前保留任务分支，不合 dev/main。
