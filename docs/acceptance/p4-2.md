# P4-2 — 视觉/交互原型与库选型

> 状态：进行中（2026-10-09）。前置 P4-1 已验收；当前产品仍为 1.0.0。原型不连接模型、IPC、用户 SQLite 或实际任务。

## 预写方案与出口

从 dev `f40f2ca` 切 `feat/p4-2-desktop-prototype`。仅新增独立 `prototypes/desktop-v2` 样例及设计/证据；不接入生产入口、不更改运行宿主/权限/接口，因此无需产品数据迁移或 architecture 接口变更。

视觉主张：石墨/纸白双主题、低对比表面、精准排版，以单一靛蓝色标识当前动作，主阅读区优先。
内容分工：紧凑导航定位模块、项目列表找上下文、中间阅读与底部输入、按需详情承载任务/审批信息。五页各有主动作，控件不用阶段编号或设计术语。
交互主张：工作区短淡入、详情短距离展开、任务移动连续落位；减少动态时不位移，状态变化不等待动画。

1. 独立 React 19 原型覆盖会话、指挥官、看板、审批、设置；包含空/加载/错误与长中文内容；960×640 / 1280×800 / 1440×900 × 深浅主题，可实际操作和审阅。
2. 精确锁定候选版本及传递依赖，读取安装包 LICENSE 与 peerDependencies；实测 Motion、react-resizable-panels、Markdown 对照。cmdk/Sonner 核对许可与接口，保留/淘汰依据写设计记录，不提前安装到生产依赖。
3. 使用当前 Tauri 壳+隔离配置/数据库加载原型，实际原生 WebKit 检查 React 19、分栏鼠标/键盘、Markdown 中文/未闭合代码与链接边界、确认焦点及减少动态；不能把浏览器通过当作原生通过。
4. 原生窗口截图覆盖三尺寸×双主题关键页，录像覆盖工作区切换、详情展开、看板落位三类动效；记录实际结果与限制，不宣称产品功能已上线或性能预算已通过。
5. `just verify` 与独立原型 build 全过；文档链接/围栏、`git diff --check`；无真实配置/密钥/DB/日志入仓，无遗留验收进程。同步 roadmap、设计与索引，出口全过后 --no-ff 合 dev，下一项 P4-3。
