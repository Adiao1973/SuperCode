# P4-10 — 流式 Markdown 与代码阅读

> 状态：已验收（2026-10-11），前置 P4-9 已验收；版本仍为 1.0.0。

## 预写设计与出口

1. architecture P4-10 先定义内容/安全/性能边界；采用 P4-2 首选轻量组合及按需高亮，无后端/迁移变化。
2. 先写失败测试：中文与未闭合代码/表格/链接增量，流末/历史一致、精确代码与全文复制、原文切换、HTML/危险 URL/图片无执行请求、外链确认取消/打开、超限回退和高亮边界。
3. `just verify` 全绿；同工具构建记录首包 gzip 和 lazy chunk，初始 JS 增幅≤20%。
4. 隔离 `pnpm tauri dev`（临时 DB/XDG、无 key、合成 ACP）核对中文/半闭合语法、长代码横向阅读/复制、原文回退、深浅/减少动态、960×640/标准窗口、20Hz 虚拟列表增量及历史重开；不使用浏览器小样例替代原生 WebKit。
5. 归档测试/原生/包体证据，更新 roadmap/入口/设计/测试说明，核对链接和 diff，清理验收进程，再 --no-ff 合本地 dev；未过则待验收。下一任务 P4-11，不推送发布。

## 当前结论

P4-10 自动与 macOS 原生出口已通过，按流程合入本地 dev。版本仍为 1.0.0，未推送/发布；下一项 P4-11 尚未启动。

- 设计提交 `a11df29` 在实现之前。正文使用同一延迟加载 renderer，流中合并解析；原文与落库文本不改写。代码按需高亮、精确复制，原文/全文复制常显；无后端 IPC/数据库迁移变化。
- 先写的测试在缺少 MessageMarkdown 时失败，最终 16 文件/53 项前端测试通过；Rust 159 通过、1 项既有 ignored，类型/构建/fmt/clippy 通过，见 [验证摘录](p4-10/verification.txt)。覆盖半闭合代码/表格/链接、持续输出不饥饿、历史一致、完成消息 DOM 保持、CRLF/引用/列表代码复制、长度/语言边界、复制和外链失败、焦点恢复。
- 采用 P4-2 轻量首选，没有引入 Streamdown。react-markdown 10.1.0、remark-gfm 4.0.1 和已有传递依赖 Shiki 4.4.3 作为直接依赖固定版本，均为 MIT，许可见 [react-markdown](p4-10/react-markdown-LICENSE.txt)、[remark-gfm](p4-10/remark-gfm-LICENSE.txt)、[Shiki](p4-10/shiki-LICENSE.txt)。Shiki 仅点击时加载 JS 引擎、6 种语法及深浅主题，使用 token span 文本，不插入 HTML。
- 同一 Vite 8.3.1 / `pnpm build`，gzip level 9：初始 entry + modulepreload 合计从 429474B 到 431433B，**+0.456%**，低于 20%。Markdown lazy entry 41842B，高亮入口 639B（还按需依赖语法/主题/共享 chunk，不能把入口大小误称全部高亮成本），见 [包体记录](p4-10/bundle.json)。既有大型 diff/语法 chunk 警告仍存在，本轮不把全量 assets 当成初始加载，也不宣称整体体积治理完成。
- 原生：使用 `pnpm tauri dev --config /tmp/sc-p410/tauri.json` 编译二进制，以临时 SQLite/XDG/PATH 包装运行；[合成 ACP](p4-10/fixture-acp.mjs) 50ms 一批，有限流，不使用真实 key/模型/工具或网络。320 条历史虚拟列表与真正重开后的代码/表格/链接一致。长 JSON 和全文复制粘回原生输入框核对；尾部两个换行保留。见 [历史高亮](p4-10/history-highlight.jpg)、[重开历史](p4-10/restart-history-dark.jpg)。
- 中文、半闭合围栏/表格/链接未崩溃，结束立即完整排版；[流中代码](p4-10/incomplete-code-dark.jpg)、[标准浅色](p4-10/standard-light.jpg)、[960×640 浅色](p4-10/narrow-light.jpg)/[深色](p4-10/narrow-dark.jpg) 可读，减少动态无逐 token 入场。168317 字符合成消息自动完整原文回退，未截断，见 [长消息](p4-10/long-raw-dark.jpg)。流中 32K 与完成 128K UTF-16 码元边界由组件测试验证。
- 外链确认初始焦点为取消，Esc 返回链接，未实际打开浏览器；真正 opener 成功/失败与显式确认边界由 fixture 测试验证，见 [确认弹层](p4-10/external-confirm.jpg)。HTML 不执行、危险链接无动作、远端图片仅替代文字，不请求。
- 原生 WKWebView dev 30s rAF 采样 1798 帧，p95 **20ms**，>50ms 为 0；可见消息挂载/移除为 0，DOM 297、图片元素/图片资源请求均为 0，见 [采样画面](p4-10/stream-metrics.jpg)、[采样脚本](p4-10/observer.js)、[结果与边界](p4-10/native.json)。这是 dev 原生帧节奏代理，不冒充 release 时间线/整阶段性能认证；P4-11 的 1000 条混合历史与阅读锚点、后续 release 性能回归仍保留。
- 验收应用已退出，本机 1450 服务已停止，临时测量配置已移出工作区；未归档 SQLite、真实连接配置或凭据。默认不加载远端图片、超限原文回退、有限高亮语言属于预写设计范围，无任务跳过。
