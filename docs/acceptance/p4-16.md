## 预写验收

- just verify：请求 UUID 共享防重、失败可重试、同名工具/重复 tool id 精确移除、裁决选项种类/来源正确；上下文/完整输入/命令/变更可读可复制，空值有说明。
- 原生 Tauri：两并发任务同名工具分属正确任务，计划内联与审批中心同一请求、连点只应答一次；会话内联与中心同步。
- 人工失败注入留卡，恢复后原选项可重试；取消挂起审批清空三处，退出后无孤儿 Agent；重启不恢复待决。
- 深浅主题/减少动态/窄窗，长命令完整复制与变更原文可读。不新增批量放行、永久规则或真实项目操作。证据归档后合 dev。
