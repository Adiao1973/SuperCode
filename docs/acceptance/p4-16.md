## 偏差、边界与集成

提交失败/重试的错误由受控前端 IPC fixture 注入，同一组件的两处卡片同时显示错误，恢复后只重试一次；没有在原生后端故意制造临时 IPC 故障，也不将此项描述为原生故障注入。原生验证的是实际后端成功/拒绝/取消/退出路径，Broker 另验证非法选项可重试。审批先到的顺序与自动裁决不得误清待决由契约测试覆盖。

修复范围包含既有 relay 生命周期、应答成功前路由被移除、裁决来源序列化与 option_id 前缀猜测；均属于本项审批一致性。新全局事件 permission-removed {ids}、DecisionRecord 可选 request_id、source 的 type 标签与桌面待决上下文同步到架构；无依赖/schema/版本变化。近期裁决仅当前进程最多 50 条，不声称重启恢复。真实模型/项目操作不在此 UI 任务验收内，既有真实出口见 P3-6。
