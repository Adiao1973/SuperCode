## 预写验收

1. 宿主服务/IPC 契约先写测试后实现：请求互斥、确认拒绝、已取消生成不创建 draft、仅本 App 取消、预检失败保留草稿；interactive_approvals 走既有询问管线，审批允许与取消裁决单次落库、独立会话归属。
2. `just verify` 全绿；配置/DB/key 不进入 Git，无新依赖/迁移。
3. macOS `pnpm tauri dev` + 隔离 /tmp/sc-p36-ui.sqlite、虚构配置/fixture key：导航/缺配置引导、填写目标和目录/规划名单、生成不执行、完整 prompt/依赖预览、必须显式确认、并发进度、内联审批允许/拒绝/取消、切换导航后台继续、错误不清空历史；截图核对布局。
4. 退出再开同库：草稿/终态/引用和结果恢复，不自动执行；运行时退出等待取消收尾，不误触其它 CLI running；已终态不可重跑。
5. 独立 macOS App 真实验收：仅内部复制本机保存 MiMo 配置/凭据至 0700 临时目录/0600 SQLite，不打印值。生成三个只回复 P36-OPEN/P36-CODEX/P36-AFTER 的 OpenCode/Codex 任务，第三项依赖前两项；审阅 prompts 后显式确认，实际进度/结果与库一致，工具数 0。完成后清除临时凭据副本，原用户库不改。Claude/MiMo ACP 环境不处理。
6. 全部范围出口通过后更新设计/README/roadmap/验收索引，任务 --no-ff 合 dev；不发布、不开发 P3-7。

## 偏差与范围

初次 macOS ⌘Q 验收发现原生菜单 Quit 直接 terminate，留下 running；修为自定义退出菜单调用 AppHandle.exit，再由 ExitRequested prevent_exit→cancel→等待 guard/driver 清理→exit。复验 running→cancelled，已完成独立任务保留；旧失败记录不改写为通过。强制结束进程或操作系统直接终止不保证收尾，历史 running 仍按非当前 App 管理显示，不猜测/误改其它 CLI 的状态。

恢复仅指历史/草稿/结果恢复，不是自动续派任务。Windows 实机专项待 P3-8/9；P2-6 延期、Claude 与 MiMo ACP 环境仍按既有范围不处理。本次真实 MiMo 使用直连 API，与 MiMo ACP 无关。
