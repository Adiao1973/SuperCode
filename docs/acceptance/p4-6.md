1. 先更新 architecture §11 的宿主/焦点约定，无新增 IPC/迁移/依赖。导航折叠有 aria-expanded、可读名称、当前页语义；审批计数跟随真实 PermissionCenter 队列更新，项目上下文与现有会话/工作空间一致。
2. 组件验证真实 App + RunConsole：草稿切页保留，挂起运行切页后 Channel 继续更新且不重派；隐藏页 Cmd-R/Cmd-. 不运行/取消，组合输入和弹层不抢快捷键。终端的 open/close 调用数验证切页不重建；不改变会话间切换行为。
3. 产品 Radix Popover/Dialog 验初焦、Tab/Shift-Tab 圈定、Esc 与回焦；Esc 不执行计划、不裁决权限，确认仍需显式点击；页面标题不出现 P 编号。指挥官内容重设计仍属于 P4-14。
4. `just verify` 全绿；隔离 Tauri 产品入口实测 960×640 与 1280×800 深浅、导航/项目弹层键盘、草稿切页、实际 PTY 切页保留并显式关闭。原生指挥官确认通过纯合成数据库 draft 打开，Esc/焦点检查不调用模型/执行 agent。
