# P3-2 直连 LLM 客户端与配置验收

## 预写步骤

1. `just verify` 全绿；配置检查及本地 HTTP fixture 确认模型、Bearer 头、独立用户目标、名单过滤、请求/响应契约。
2. fixture 验证 HTTP 非 2xx、重定向不跟随、超时、取消（含读响应阶段）、空内容、截断/非法 JSON、非法计划及响应过大；错误不得包含测试 key 或服务端响应原文。
3. CLI 独立配置/环境变量/SQLite：plan generate 输出合法 P3-1 plan/batches；失败非零，Ctrl-C 及时结束，显式 --config 时数据库未创建；默认从 SQLite 读取配置，不创建会话、不派单。
4. 用户指定 endpoint/model/key 来源后，真实目标“为一个待办应用提出开发计划，不执行任务”生成合法计划；本地 validate 再检查通过，留痕 provider/model/结果（不归档 key）。
5. 满足以上出口后更新文档/roadmap，任务 --no-ff 合 dev；没有真实访问方式时保留进行中，不伪造通过。

6. SQLite 配置保存/重读/无效配置回滚测试；macOS 设置页只填虚构连接信息，保存后重新进入与重启恢复一致。真实连接信息和 key 不写入 repo，数据库与 WAL/SHM 被忽略。MiMo 连接信息允许用户稍后提供；实际模型验收在提供后完成，之前不合 dev。
