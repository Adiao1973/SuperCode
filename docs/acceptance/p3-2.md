CLI 真实复核同样通过：默认 SQLite 凭据生成 8 任务、7 批次。generate 的输出是 ValidatedPlan 包装（plan/batches），因此先提取 plan 再交给 validate，退出 0；不能把整个包装直接当 TaskPlan 校验。验收命令：

```sh
./target/debug/supercode plan generate '为一个待办应用提出开发计划，不执行任务' > /tmp/sc-p32-real-envelope.json
python3 - <<'EXTRACT'
import json
from pathlib import Path
v = json.loads(Path('/tmp/sc-p32-real-envelope.json').read_text())
Path('/tmp/sc-p32-real-plan.json').write_text(json.dumps(v['plan'], ensure_ascii=False))
EXTRACT
./target/debug/supercode plan validate /tmp/sc-p32-real-plan.json > /tmp/sc-p32-real-validated.json
```

输出仅留本机临时文件，不归档用户实际计划或配置。App 和 CLI 为独立模型调用，任务数量不同是正常的生成差异。
