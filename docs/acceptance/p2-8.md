# P2-8 看板拖拽验收

1. `just verify` 全绿；数据库契约测试验证跨列/跨空间原子更新、非法空间/状态不改变数据、会话引用和执行 cwd 保持、重新打开数据库状态保持。
2. macOS 拖拽把手跨列，空列高亮且松手后即时归列；跨项目/默认空间移动任务，SQLite 目标空间与状态一致。
3. 空格拾取、方向键选择目标列、空格放下；Escape 取消以及落在看板外不改变任务。绑定/删除/推进按钮不触发拖拽。
4. 已绑定会话移动后仍可跳转，session_id 不变；已有 worktree 的任务跨空间后复用原目录，草稿/运行仍归原项目空间。
5. 重启应用，任务目标空间/状态/绑定恢复；模拟后端目标空间不存在，卡片回滚并显示错误。
