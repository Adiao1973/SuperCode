## 预写设计与出口

视觉：沿用石墨/纸白与单靛蓝，动效短促、安静。内容：设置新增动效偏好，已有复制反馈使用存在变化，不重做页面。交互：完整模式轻微淡入/8px 落位与退出，减少模式即时静态反馈；导航/操作颜色使用统一短时 token。

1. 先提交 architecture §6.9，迁移 0009 与严格 DTO 测试先行；旧 0008 库升级后主题/会话/凭据不丢，motion 默认 system，保存重开保留，非法值拒绝且不覆盖旧值。
2. 产品设置选择 system/reduce/full，保存成功再应用，失败保持旧值，启动失败保守 reduce 并可重试；matchMedia change 与卸载清理有真实 Provider 测试。
3. Motion 14.0.0 / MIT（P4-2 已选型），LazyMotion strict + async domAnimation，仅 m；无同步加载完整引擎，无第二引擎。构建验证独立特性 chunk，加载失败静态可用。
4. 复制短反馈存在变化、统一 CSS 时间/缓动、CSS spin/pulse 与 xterm 光标受偏好约束。减少模式无位移/持续闪动；审批与取消不等动画，既有事件回放及一次性裁决继续通过，不以布局重构扩项。
5. `just verify` 全绿；隔离 Tauri 产品入口真实操作三模式/复制反馈、保存重启、深浅/最小窗口，原生 getAnimations/计算样式记录完整与减少差异。系统实时变化由受控 media fixture 验证，不改用户 OS 设置；原生系统模式读数与 OS matches 一致。截图/读数归档，不用 jsdom 冒充真实动画。
6. 清理验收 App/Vite；更新根 README、文档索引/设计/roadmap，检查链接/秘密文件/差异后 --no-ff 合 dev。下一任务 P4-6，不发布/推送。
