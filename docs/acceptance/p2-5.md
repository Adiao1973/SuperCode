# P2-5 MiMo ACP 接入验收

## 预写验收步骤

1. `just verify`：前端构建、Rust fmt/clippy/test 全绿；MiMo 注册表命令、能力位及选择器/指引的确定性检查通过。
2. 从官方 npm 包临时安装 MiMo CLI，不修改全局安装；`mimo --version`、`supercode detect` 显示 MiMo 版本。未安装时设置页提供可复制安装命令和认证说明。
3. 在独立 `/tmp/sc-p25-*` 工作目录用 CLI `run --agent mimo` 完成真实任务：写 `hello.txt`、读回、流式消息及工具事件可见；如发生 ACP 权限请求，在 CLI 或桌面内联卡片应答，并以 EndTurn 收尾。认证或模型选择由 MiMo 自身管理，不读取用户凭证。
4. 使用数据库记录的本地 UUID 新进程 `resume`：以原 MiMo agent/cwd/ACP session id 加载历史，准确复述文件内容与暗号。
5. macOS 桌面新会话可选择 MiMo；与另一 ACP agent 同时运行时，消息、工具、审批、状态各自归属正确。关闭重启后 MiMo 历史仍绑定 MiMo，并可续聊。
6. 若官方 CLI 在当前环境缺少可用认证或模型服务，记录精确阻塞和已通过的协议/界面范围；不以安装探测代替真实任务通过，也不提前把 P2-5 标为已验收。

## 阶段结果（2026-09-29，尚未通过完整验收）

- 官方 `@mimo-ai/cli` 0.1.15 安装在 `/tmp/sc-p25-mimo`，未改全局 CLI；`mimo --version` 与设置页探测均显示 0.1.15。独立 XDG 配置、数据、缓存与 SuperCode SQLite 均在 `/tmp/sc-p25-*`。
- `just verify` 全绿：前端构建、Rust fmt/clippy、core 65 passed / 1 ignored、ACP 合同测试 4 passed、desktop 2 passed。新增测试覆盖 MiMo 从会话 cwd 启动、旧注册表兼容、嵌套 IPC 字段，以及 ACP 空轮次错误。
- 首次从仓库目录启动 `mimo acp`，会话 cwd 指向 `/tmp`，`session/new` 失败。MiMo 日志明确记录 `directory_not_allowed`；只附加 `--cwd` 无效，0.1.15 的服务根目录仍是进程当前目录。改为从会话 cwd 启动子进程后，同一命令可获得 `ses_...` ACP session id，数据库保存 `agent_id=mimo`、原 cwd 与状态；跨进程 `resume` 使用同一 ACP session id 完成 `session/load`。
- MiMo 自带的匿名 MiMo Auto 通道在临时配置中可初始化，但原生 `mimo run --model mimo/mimo-auto` 返回 `MiMo free API service has ended. Sign in or configure a third-party API.`；ACP 请求则返回 0 token、无消息或工具事件的 EndTurn。为避免误报，驱动现将这种空轮次报错并把会话标为 failed。CLI 退出码为 1，桌面会话显示“出错”和模型/认证提示。
- macOS 临时应用中，新会话可选择 MiMo，折叠指引含官方安装命令及 `mimo providers login`；设置页显示 MiMo 0.1.15。失败会话在应用重启后仍保留 MiMo agent 与原 cwd，历史可打开。
- 为隔离真实模型不可用的问题，在独立 XDG 临时配置中将 MiMo 指向本机 `127.0.0.1:18765` 的一次性 OpenAI 兼容模拟端点（固定响应，无外部模型调用）。真实 MiMo ACP 进程经该端点流式回复 `P25-MOCK-READY`；新进程 `session/load` 重放并续聊均通过。模拟端点发出 write → read 工具调用时，CLI 展示两次 `external_directory` 权限请求，分别选择一次允许；工具状态均为 Completed，`mock.txt` 内容为 `P25-MOCK-FILE`，数据库记录 2 次工具调用与 2 次审批。桌面内联卡片复核同一顺序、完整路径、两次 Allow once、读回内容与最终回复，数据库会话状态为 completed。

尚未通过：由**真实模型**驱动的写入/读回、有效上下文续聊，以及与另一 agent 的真实并行任务。模拟端点只能证明 MiMo ACP 与 SuperCode 的协议、工具和审批链路，不能替代模型行为验收。需在 MiMo CLI 中配置可用供应商后重跑第 3—5 步；不在本记录中把协议建会话或空 EndTurn 视为任务成功。凭证无需提供给 SuperCode 或聊天。
