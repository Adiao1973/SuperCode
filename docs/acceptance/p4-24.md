## 预写验收（2026-10-19）

1. 保持 [P4-23](p4-23.md) 通过范围：macOS Apple Silicon。Windows、ZCode、Claude 本机登录问题仍按用户授权延期；NativeDriver 限核心协议，不声明 Intel 实测。签名/公证如实记录，不以 ad-hoc 冒充 Developer ID。
2. workspace、三个 Rust 包锁版本、桌面 package 和 Tauri 配置统一 2.0.0；新增版本一致性检查进入 `just verify`，对错版/缺项/锁文件漂移给出失败。完整检查全绿。
3. `pnpm --filter @supercode/desktop tauri build` 生成原始 release App 和 arm64 DMG。核对 Info.plist、Mach-O、实际签名与公证状态、DMG 挂载、SHA256/大小。仅上传实际产物，不上传 SQLite/凭据/个人日志。
4. 只读挂载 DMG，用 ditto 将原始 App 复制到专用临时安装目录，不改 bundle、可执行文件或签名，不覆盖个人安装。以独立 SQLite 启动，确认实际 v2.0.0 和五页入口，真实 ACP 无工具标记任务完成；结果与 cwd 重启恢复、无误执行；真实 PTY 的 pwd/中文/退出码正常。必要时复用 P4-23 的真实 OpenCode 隔离后端配置，仍运行真实 CLI，不用 fixture 代替推理。
5. 建立 [Phase 4 阶段验收](phase4.md)，引用 P4-1～23 的性能/可访问性/升级/真实全链路证据。同步用户 README、架构交付说明、roadmap、文档索引；历史发布范围与当前状态明确区分。
6. 本地通过后 `--no-ff` 合 dev，在 dev 再跑 `just verify`；创建 annotated `v2.0.0`（不移动已有 tag），再 `--no-ff` 合 main。推送 main/dev/tag，发布 GitHub Release，上传原 DMG 与 SHA256SUMS.txt；检查远端 refs、Release draft/prerelease 标志、资产大小和服务端/下载 SHA256。网络或认证失败保持远端待验收，不宣称已发布。
7. 退出验收 App、卸载 DMG、清理隔离凭据与测试子进程；保留可审计的去敏证据和原始包。不得读取或修改个人会话历史。
