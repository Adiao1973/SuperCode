## 取舍与限制

- Agent 选择依据已注册 ACP 定义，不做版本探测；“已接入”不等于本机安装或认证成功，执行阶段仍预检。设置页原有版本探测与本轮生成过程分开计数，未以 fixture 的版本号冒充真实 Agent 验收。
- 只新增专用目录选择/校验 Rust IPC，未增加通用 JS dialog capability；原生目录选择不读取项目文件、不新建目录。生成时再次检查目录和 Agent ID，防止绕过前端或选择后目录消失。
- 新依赖仅目录选择插件；锁定 dialog 2.4.2、传递 fs 2.4.4，二者 MSRV1.77.2、MIT/Apache-2.0。所有原有锁定包版本保留；没有升级 Tauri 框架。SQLite schema 不变，真实配置、凭据、数据库未入仓库。
- 本任务验证交互和 draft 生成边界，真实模型/双 Agent 执行全链路由已有阶段验收及后续 P4-23 负责。审阅确认、执行监控重构留给 P4-14/15。
- roadmap、architecture、README、设计状态及测试说明已同步；本地任务分支 --no-ff 合 dev，不推送、不改版本、不发布。
