## P1-10 整体验收剧本（预写，执行时勾选）

1. `just verify` 全绿；`just build`（或 `pnpm tauri build`）产出可运行 .app；
2. .app 首次启动：安装探测引导可见（P1-7），可复制安装命令；
3. 端到端：新建会话跑真实任务（限流解除后）→ 流式渲染 → 审批应答 → 完成落库；
4. 重启 .app：历史会话恢复、续聊上下文有效、删除会话级联生效；
5. 全部通过：dev 打 tag v0.2.0 → 合回 main → 更新 README。
