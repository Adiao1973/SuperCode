# P2-3 Claude Code 接入验收

## 预写验收步骤

1. `just verify`：构建、fmt、clippy、测试全绿；覆盖非 ACP 拒绝、续聊 agent/cwd 校验与能力位。
2. `pnpm tauri dev`：新会话选择 Claude Code；已有会话 agent/cwd 锁定；OpenCode 专属配置提示不出现；Node/npx 状态和可复制安装/登录指引可见。
3. `SUPERCODE_DB=/tmp/sc-p23.db cargo run -p supercode-cli -- run --agent claude-code --cwd /tmp/sc-p23 "创建 hello.txt，内容为 hi，然后读取它"`：流式消息、工具事件、审批应答与文件内容正确。
4. `SUPERCODE_DB=/tmp/sc-p23.db cargo run -p supercode-cli -- sessions list`，随后 `resume <UUID> "继续，刚才的文件内容是什么？"`：仍选择 Claude Code，session/load 成功，回答 hi。
5. 重启桌面：Claude 历史会话恢复原 agent；OpenCode 历史仍可用。缺失 Node/npx 时显示安装引导（自动测试模拟缺失程序）。

### macOS WebKit 桌面实测

使用本轮 debug 可执行文件，临时独立 `.app` 标识（便于 UI 自动化区分旧发布版），
Vite `localhost:1420` 与 `/tmp/sc-p23-ui.db` 独立数据库。

- 新会话下拉可选 Claude Code；ZCode 显示尚未接入并禁选。
- 选择 Claude 后 OpenCode 配置提示消失；显示 Node v24.12.0 / npx 11.6.2。
- 安装/认证折叠区可展开，可复制 Node 安装、adapter 检查、登录命令；补充 API Key/网关方式和 GUI 环境继承说明。

- 关闭并重启应用，历史列表保留会话；点击历史后仍为 `claude-code`，cwd 为 `/tmp/sc-p23-ui`，两轮消息完整，agent/cwd 保持锁定。
- 新草稿默认仍为 OpenCode；OpenCode 专属检查仍显示。旧 OpenCode 真实续聊本次未额外消耗模型调用，既有回归测试保留。
