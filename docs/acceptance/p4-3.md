## 预写方案与出口

从 dev `a2a51bc` 切 `feat/p4-3-frontend-verification`。本轮为测试基础，不改变现行 IPC/数据模型，不引入 P4-4 主题或 P4-9 输入功能。

1. 精确锁定兼容当前 React/Vite 的 Vitest、Testing Library、user-event、jest-dom 与 jsdom 为开发依赖。新增 `test` / `test:watch`，`just verify` 包含非 watch 测试；零测试须失败。
2. 测试层在 Tauri 模块边界替换 invoke/Channel/listen，默认拒绝未声明命令；真实 key、API、SQLite、Agent 与 PTY 不可访问。提供按批/显式时钟推进的合成事件，测试卸载/取消后不再投递，状态跨测试隔离。
3. 保护真实 stream/sessions reducer 的中文增量、完成/错误、后台会话路由、历史幂等与同名工具审批隔离；保护 run_prompt 参数及批回调，审批事件注册/释放；组件验证 PendingCard 禁用与裁决回调。
4. 提供 matchMedia 可变 fixture 与独立交互样例，建立系统深浅/减少动态、composition 输入、Dialog Tab/Esc/回焦方法。明确样例用于验证测试方法，不代表尚未开发的主题/输入功能；jsdom 不代替原生输入法、布局或动画。
5. 负向对照：临时破坏一个真实 reducer 行为，指定测试须失败，恢复后通过；不提交故意失败实现。
6. `just verify` 全绿、测试 TypeScript 检查、链接/围栏与 diff 检查；使用隔离 Tauri dev 壳走查样例并留痕，无真实配置和进程残留。出口全过归档并 --no-ff 合 dev；下一任务 P4-4。
