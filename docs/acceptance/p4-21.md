## 小设计与预写验收

1. 同设备 release、P4-1固定合成历史和20Hz ACP fixture；另补至少100个工具节点。固定初始12会话/1022消息；实验中累计生成的会话必须另注明，最终对照使用新隔离库，不将累计数据偷作同口径。
2. 从Vite manifest的唯一entry沿静态imports递归去重，逐文件gzip level9；dynamicImports不计首包。基线369794×1.2，检查接入just verify；缺失/歧义依赖失败关闭。
3. 原生WebKit临时探针记录≥30次输入/点击到双rAF绘制机会近似值p95≤100ms；30s滚动/拖动/20Hz追加rAF p95≤20ms。原始样本、视口和可见性留痕。rAF不等于合成器FPS或精确像素反馈，IME组合另测。
4. 1000混合消息/20Hz不丢事件，虚拟DOM、离底提示和锚点正确；20次终端/切页无自有进程残留或持续宿主RSS增长。5次进程冷启动AX-ready上界中位数≤821.7ms，同场景宿主RSS≤基线120%。此比较沿用P4-1宿主口径，不能据此声称整个App没有泄漏。
5. 超预算修复/拆任务，不绕过预算；全部出口完成、文档同步后才--no-ff合dev，不提前下一阶段。最终视觉/文案优化按用户要求留到版本完成后。

## 保留的实现

- 首包检查进入just verify，测试共享/传递/循环依赖及按需排除；支持默认dist与`--json`报告，见 [工具说明](../../scripts/performance/README.md)。
- xterm/SessionTerminal改为React.lazy按需加载，打开时有加载状态，失败可关闭终端，模块错误需重启应用重试；加载完成前关闭不会挂载/创建PTY。新增测试覆盖该生命周期，原终端切页与关闭规则保持。
- 活动Markdown解析阈值从32K收紧到4K UTF-16码元；长消息保留完整原文，结束后恢复原有完成态128K阈值。Markdown及原文均100ms合并展示更新，复制始终使用完整权威源。
- 活动原文按1024码元后首个换行切稳定块，以memo及layout containment减少末块追加时的重排；不拆单行/Unicode代理对、不丢内容。测试覆盖稳定前缀、原文/复制完整性和完成态恢复。
- 时间线不再每批无条件校正布局；新增条目立即校正，正文变化由既有MutationObserver/ResizeObserver处理。最终混合场景的切页/展开锚点保持正确。
- 无新增依赖、IPC、schema或真实模型调用。没有把预算未通过的项写成已验收。

## 调查与被撤回实验

[原始数字](p4-21/samples.json) / [摘要](p4-21/summary.json)保留失败样本：初始流式22ms；8K阈值28ms；合并展示27ms；4K稳定块22ms。峰值间隔有所下降，p95仍不达标。实验累计会话数和采样时刻不同，不能据此声称严格A/B提升。

WebKit [时间线数字诊断](p4-21/timeline-diagnostic.json)显示布局p95约10ms、脚本事件约4.6ms；未见>50ms脚本事件。Inspector打开时有额外开销，嵌套事件不可相加成墙钟时间。含截图的原始时间线约171MB，仅留临时目录，不进仓库。longtask observer不支持。

SQLite setup预热、提前到layout effect显示窗口、纯正文startTransition均未改善目标，已撤回。相关启动样本：[原始915ms](p4-21/startup.json)、[终端按需937ms](p4-21/startup-lazy.json)、[就绪阶段959ms](p4-21/startup-layout-ready.json)。旧版首次对照使用新版迁移库失败；改用旧版自行初始化的新库后读出12历史，单次714ms只作为调查，不能替换五次基线747ms。

锁屏后未启动fixture的样本、Inspector使消息区高度0的锚点样本，以及混合记录中Inspector干扰的帧样本均不计通过。延迟读取在关闭Inspector2秒后进行：切页前后与展开后相同key/偏移，height由125867→126014px而锚点不变。普通流式8个已完成验收会话均完整保存0～899片段，见 [审计](p4-21/stream-storage-audit.json)。
