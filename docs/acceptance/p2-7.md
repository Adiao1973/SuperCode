# P2-7 任务 worktree 验收

1. `just verify` 全绿；临时 Git 仓库契约测试证明独立分支/目录、幂等复用、原工作区不变、include 文件复制及路径/符号链接拒绝、失败回滚。
2. 项目空间创建任务，点击隔离会话：cwd 是独立 worktree，标题预填，原项目空间归属保留；运行产生会话后任务绑定并进入进行中。
3. 修改隔离目录中的 tracked 文件，主工作区文件保持原内容；重启可复用原 worktree。
4. 删除任务后清扫：脏目录和有会话引用的目录保留；无引用且干净的孤儿移除，分支/提交保留；其他 Git worktree 不受影响。
5. macOS 桌面核对按钮、提示、分组和绑定；锁屏时如实记录待补验。

- `just verify` 退出 0：前端构建、fmt、严格 clippy；核心 69 passed / 1 ignored、ACP 协议集成 4 passed、桌面 2 passed、doc tests 全绿。新增四个真实临时 Git 仓库契约测试，无模型/网络依赖。
- 契约覆盖：HEAD 基线、不复制主目录未提交源码、独立分支与幂等复用、原项目改动保持；include 普通文件复制，拒绝绝对路径/../.git/符号链接/跟踪文件；复制中途失败回滚目录和新分支；脏目录及任务/会话引用保护，保留分支及其他 worktree；外部删除目录后只注销对应 Git 登记，不全局 prune。
- macOS 临时 SuperCode P27 应用 + 独立 SQLite + `/tmp/sc-p27-ui-project` 实测：从项目任务点击“隔离会话”，自动填提示词和独立 cwd；Agent 可选，cwd 锁定。
- 真实 OpenCode ACP 运行任务将 source.txt 写为 `P27-ISOLATED` 并 Read 确认，工具时间线完整、EndTurn。主工作区 source.txt 仍为 `original`。任务自动进入 in_progress 并绑定 agent session；SQLite 会话 workspace_id 与原项目一致，不新建 worktree 空间。

- 无新增依赖、无数据库 schema 变更。`.worktreeinclude` 当前为显式文件清单，不支持 glob/目录或 symlink；清扫保守保留包含 ignored 文件（包括复制的配置）的孤儿，避免丢失本地配置；分支及提交始终保留。
