# P4-4 — 设计 token、主题与外观偏好

> 最终结论：已验收（2026-10-11），按流程合入 dev。主题与本机持久化、旧库保留、原生深浅核对及完整检查通过。版本仍为 1.0.0，下一任务 P4-5。

## 预写方案与出口（2026-10-10）

从 dev 切 `feat/p4-4-appearance`，接口与迁移先写 architecture。视觉：石墨/纸白表面、靛蓝主操作、系统中文字体与等宽代码；内容仍沿用五页布局，仅设置增加外观区。主题立即切换、不做整屏过渡；本轮不实施 P4-5 动效。

1. 新增 SQLite 0008 单例 appearance_preferences，仅保存 system/light/dark，不读写凭据；旧库默认 system。IPC get/save 严格枚举、未知字段拒绝，事务性保存失败不覆盖现有值。
2. 窗口初始隐藏，前端读取 SQLite、应用 resolved theme 并提交首帧后，通过只操作当前窗口的 appearance_ready 设置背景并显示；不以 localStorage 代替事实源。加载失败回退系统并显示可重试错误，不让窗口无限隐藏。深浅/系统主题、系统 change 订阅、保存错误及重启恢复有自动测试。
3. 统一字体/spacing/radius/表面/语义色/焦点/禁用控件 token；正文与 muted 及语义文本在实际表面达到 4.5:1。终端/diff 跟随主题，切换不重建 PTY 或执行宿主。
4. Rust 契约测试先写：合法枚举、默认、文件重开、1.0 旧迁移库的合成会话/凭据升级后不丢；前端使用 P4-3 fixture 测真实设置/启动/系统变化，不以样例代替产品实现。
5. `just verify` 全过；隔离当前 Tauri App 实测设置保存、五页深浅主题、重启恢复和首帧主题，三尺寸关键页无遮挡，实际 CSS 对比度留读数。真实配置/key/数据库不入仓；清理验收进程，同步文档后 --no-ff 合 dev，下一任务 P4-5。

```sh
just verify
# SUPERCODE_DB/XDG_CONFIG_HOME 指向纯合成临时目录，Tauri dev 加载产品入口。
git diff --check
```

## 闭环结果（2026-10-11）

- `just verify`：前端 25 项通过，Rust 153 项通过、1 项既有 opencode 冒烟忽略；测试类型检查、生产构建、fmt、Clippy 全过。[检查摘要](p4-4/verification.txt)。首次完整检查修正测试模块顺序/格式；沙箱禁止本机 HTTP fixture 监听造成 EPERM 后，在获准本机监听环境重跑通过，没有真实模型请求。
- 数据库：契约拒绝非法枚举/未知字段；保存失败保留旧值；迁移至 0007 的文件库注入纯合成会话与假凭据，升级 0008、保存、关闭重开后全部保留，默认 system。
- 前端真实 Provider/设置组件：系统变化仅影响 system，保存失败与 pending 不切换旧主题，超时回退不覆盖 SQLite，应用根主题后才请求原生窗口显示。终端测试校验已有实例颜色更新，open_terminal 不重复，卸载才 close；未修改执行宿主。
- macOS 原生：`pnpm tauri dev` 构建产品入口，隔离 `SUPERCODE_DB`、`XDG_CONFIG_HOME`、1444 devUrl，CUA 通过同一 debug binary 的临时 .app 操作。固定浅色/深色保存后分别退出重启恢复，首次可见截图主题匹配（[浅色](p4-4/restart-light.jpg)、[深色](p4-4/restart-dark.jpg)）；标题栏随主题同步，[系统模式](p4-4/settings-system.jpg)恢复当前 OS 深色。启动顺序另由自动断言保证；截图不是逐帧录像，不声称测得帧级闪烁时长。
- 五页深浅色、960×640 / 1280×800 / 1440×900 窗口均留图：设置主题和导航可达，会话主操作未遮挡；长设置页保留纵向滚动。截图尺寸为窗口逻辑尺寸的 2×，含原生标题栏。列表使用纯合成空闲会话，看板/审批为空态；未拿空态截图替代运行/审批交互的既有回归。
- 对比度：原生 WebKit `getComputedStyle` 解析 CSS 变量到 sRGB，按 WCAG 相对亮度计算；每主题 18 对，浅色最低 5.011:1、深色最低 6.613:1，见 [原始颜色与读数](p4-4/contrast.json)。范围为正文、muted、成功/警告/错误与背景/card/muted，以及主操作/选中/导航选中文字；排除禁用控件、装饰边线和任意终端 ANSI 色。
- 无新增依赖，无 key/API/真实用户数据库入仓。临时验收 App 已退出、Vite 已停止，1444 无监听。原用户 App 与配置未改动。版本保持 1.0.0，当前下载包不更新；下一任务 P4-5。
