## 执行结果

- 文档先行提交 `0f4cc7c`，实现/测试/CI 提交 `58694f8`。本次没有 UI 布局、数据库迁移、模型接入或发布改动。
- Windows ProcessManager 启用 Job kill-on-close；Windows ACP 使用 owned ProcessManager stdio 接 SDK ByteStreams，原生 current_dir；显式收尾和 future drop 清理。新增原生 Job 包装供 ConPTY shell 绑定，绑定失败不降级放行。

- 路径探测支持 Windows 可执行后缀与常见 GUI PATH；版本检测与启动共用命令解析，支持引号路径和结构化配置。CLI fixture 使用 SUPERCODE_AGENTS 隔离注册表，避免依赖 Windows HOME 行为；持久化测试改用平台临时目录。
