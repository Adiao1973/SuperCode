# P2-9 会话内嵌终端验收

1. `just verify` 全绿；PTY 契约测试覆盖绝对目录校验、读写、resize、关闭与自然退出回收及子进程清理。
2. macOS WebKit 会话可打开终端，`pwd` 与会话实际 cwd 一致（含 worktree）；中文、ANSI、交互输入、Ctrl-C 正常，不透明背景无绿色伪影。
3. 面板 resize 后 `stty size` 更新；终端焦点不触发会话运行快捷键。
4. 关闭运行中的 shell（含 sleep 子进程）、切换会话/页面、启动时关闭、退出应用均回收进程；重复打开可用，终端自然 exit 后可关闭重开。
5. 无效 cwd 显示错误且不创建目录；重启历史会话终端使用原 cwd，不持久化旧 shell。
