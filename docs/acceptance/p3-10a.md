## 预写验收（2026-10-07）

1. 从 dev 建 feat/p3-10a-macos-regression，预写本剧本。macOS Apple Silicon 为本机平台；Windows P3-8/9、ZCode P2-6 延期，Claude ACP 本机环境不处理，NativeDriver 保持核心库范围。

3. 真实 MiMo 生成三任务 OpenCode/Codex 计划，固定回复 P310-OPEN/P310-CODEX/P310-AFTER，第三项依赖前两项，禁止工具/文件。审阅 prompt/agent/依赖后显式确认；无确认不得执行。双根完成后才运行后代；报告与重启读取一致，工具数 0。错误/认证不可用不能伪记成功。
4. macOS 桌面实际生成/预览/确认/进度/会话引用/结果，导航后继续、重启结果恢复不自动重跑；本地 fixture 核对审批允许/拒绝、取消、后代门禁及 App 退出收尾。截图检查可读布局；遇到回归先补测试再修复。
5. 回归会话及历史、项目/worktree 归属、看板移动、内嵌终端中文/ANSI/resize/Ctrl-C/关闭重开与退出清理。只操作本次临时项目/数据，不修改日常会话或个人配置。
6. 核对真实/fixture 状态、会话、审批、结果及文件副作用；测试目录内凭据副本在结束后清除（secure_delete/checkpoint/VACUUM），原库只读。文档/README/roadmap/索引一致、相对链接有效，全部通过才 --no-ff 合 dev。安装包与发布归 P3-10B，当前仍 v0.3.0。

## 回归缺陷与修复前复现

- 当前 Debug App：将窗口从约 1280×800 缩至约 1078×650 CSS 像素，会话控制栏仍强制单行，预授权规则被挤成逐字竖排，整个页面被撑高。工作目录较长的隔离会话可稳定复现；终端 PTY 尺寸本身正确从 16×113 同步为 16×82。
- 先记录失败场景再修复：控制栏允许换行，规则编辑区保留可读最小宽度；重建后在相同窗口、相同会话复验，要求规则可读、运行按钮与终端仍可操作。仅调整布局，不改权限语义或接口。

## 偏差与范围

- 自动与实际桌面验证使用当前源码打出的 Debug App，而非 dev watcher，避免 HMR/开发态影响生命周期；修复后重新构建并复验受影响 UI。
- 新发现的布局问题只修改内部 CSS 类，无接口、数据模型或权限行为变更，architecture 无需改动。UI 失败复现先写入上节，没有新增重复实现的测试或依赖。
- scheduler-agent fixture 宣告 loadSession 但没有实现 session/load；对该 fixture 尝试恢复执行会超时，不能当作真实 agent 恢复失败或成功。历史读取已通过；真实模型结果的 App/CLI 重启恢复另行通过。布局操作复验改用新 fixture 会话。
- Windows P3-8/P3-9、ZCode P2-6 与 Claude ACP 本机认证排除项沿用用户授权；NativeDriver 仍限核心库。P3-10A 不承诺 Windows、Intel Mac、发布安装启动或签名公证。后两项中的发布安装出口归 P3-10B。
