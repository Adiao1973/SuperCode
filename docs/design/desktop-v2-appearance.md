# P4-4 外观设计

本文定义主题基础；布局见 [P4-7](../acceptance/p4-7.md)，动效见 [规范](desktop-v2-motion.md)，状态以 [roadmap](../roadmap.md) 为准；持久化/IPC 约定见 [架构 §6.8](../architecture.md#68-外观偏好与首帧p4-4)。

系统中文字体使用 -apple-system / PingFang SC，代码使用 SFMono-Regular / Menlo；基本 spacing 为 4px，基础圆角 8px。复用既有 Tailwind/shadcn token，语义成功/警告代替各页任意绿黄文字，焦点使用 2px 主色轮廓；禁用态仍沿用组件透明度。依赖未新增。

偏好只有跟随系统、浅色、深色。保存成功才切换，失败留在旧主题并允许重新读取；不使用全屏颜色动画。启动先读取本机 SQLite 并应用根主题，React 提交后显示隐藏的原生窗口；不等待 rAF，避免隐藏 WebKit 暂停绘制而无法显示。原生主题和底色一并设置，系统模式恢复 OS 跟随。

终端仅更新已有 xterm 的背景/前景，diff 使用对应 themeType。ANSI 命令输出仍由终端色表/程序控制，未声称所有 ANSI 色与禁用文字达到正文对比度。原生 WebKit 读取的 18 组正文/语义文字组合，浅色最低 5.011:1、深色最低 6.613:1，方法及原始数值见 [验收](../acceptance/p4-4.md)。
